# Spatial OS (prototype)

Get the APK without a computer:
1. Make a free GitHub account and a new repository.
2. Upload everything in this folder (keep the .github folder).
3. Open the Actions tab, wait for "Build APK" to finish (about 5 minutes).
4. Open the finished run, download the SpatialOS-apk artifact, unzip it, install app-debug.apk.
   (Allow "install unknown apps" for your browser when asked.)

The app needs internet the first time to fetch the hand-tracking model.
